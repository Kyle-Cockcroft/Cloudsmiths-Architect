# Cloudsmiths Architect — Apex Plastics

Architecture working papers for **Apex Plastics** and the **Apex Direct** direct-to-consumer (D2C) programme.

This repository holds target-state assessment material, technical notes, and supporting slide decks used to recommend how Apex should launch D2C without overloading its existing SAP and Salesforce estate.

## Primary documents

| Document | Purpose |
|---|---|
| [Apex-Plastics-D2C-Target-Architecture-Assessment.md](./Apex-Plastics-D2C-Target-Architecture-Assessment.md) | Full target architecture assessment (platforms, integration, MDM, roadmap, ADRs) |

## Architecture thesis (short)

Shopify owns the cart; Salesforce owns the customer; MuleSoft owns the contracts; SAP stays off the synchronous D2C path until a cloud ERP replaces it.
